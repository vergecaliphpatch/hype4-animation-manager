## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize Hype 4 projects with client and delivery status |
| **Scene Tracker** | Track scene and timeline structure per Hype animation project |
| **Export Config** | Save named export settings for HTML5 and web platform targets |
| **Client Notes** | Log client feedback and revision notes per animation project |
